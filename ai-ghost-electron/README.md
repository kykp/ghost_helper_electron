# 👻 AI Ghost

Невидимый AI-ассистент для собеседований и видеозвонков на macOS.

Приложение слушает **оба голоса** — ваш (микрофон) и собеседника (системный
звук), — **само определяет момент**, когда нужна подсказка, отправляет диалог
в GPT-4o-mini и показывает ответ в оверлее. Отдельный режим — **решение задач
по скриншотам**: снимаете 1-5 областей экрана и получаете разбор с кодом.
Оверлей **не попадает в захват экрана** — собеседник его не видит.

Голосовые подсказки работают автоматически; скриншоты задачи — по кнопкам.

## Возможности

- 🫥 Overlay-окно исключено из захвата экрана (`setContentProtection`)
- 🗣 Два раздельных канала речи: «Я» (микрофон) и «Собеседник» (loopback-звук)
- 🎙 Запись по репликам (VAD) — в Whisper уходит целая фраза, а не обрезок
- 🧠 Умные триггеры с приоритетом по тому, кто говорил последним
- 📋 Ответы накапливаются: краткий + развёрнутый (с кодом) + уточняющие
  вопросы. Старые блоки никогда не исчезают и не перезаписываются
- 📷 Режим «решение задачи»: снимаем 1-5 областей экрана под окном оверлея,
  получаем разбор с готовым кодом и уточняем решение голосом
- 🔁 Ручной повтор распознавания, если микрофон не расслышал вопрос
- 🛡 Антиспам: не чаще 1 запроса в 10 сек и максимум 5 в минуту
- ⌨️ Глобальные горячие клавиши, иконка в трее (без дока)

## Установка и запуск

Нужен Node.js 18+.

```bash
cd ai-ghost-electron
npm install
npm start
```

## Первый запуск

1. Нажмите **Cmd+Shift+S** — откроется окно настроек.
2. Вставьте **OpenAI API-ключ**, нажмите «Проверить ключ», затем «Сохранить».
3. Выдайте разрешения в `Системные настройки → Конфиденциальность`:
   - **Микрофон** — для распознавания вашего голоса;
   - **Запись экрана** — нужна и для скриншотов, и для захвата системного
     звука (голоса собеседника). После включения **перезапустите** приложение.
4. Готово. Микрофон **выключен по умолчанию** — включите его кнопкой 🎙
   (или Cmd+Shift+M), когда нужно, чтобы система слышала и ваш голос.

Оверлей — полупрозрачное «матовое стекло»: тёмная подложка с размытием,
чёткий светлый текст. Плотность фона настраивается ползунком. Перетаскивается
за шапку; кнопка **×** в шапке — полный выход (иконка из трея исчезает).

## Горячие клавиши

| Комбинация    | Действие                                       |
| ------------- | ---------------------------------------------- |
| `Cmd+Shift+P` | Принудительная голосовая подсказка по диалогу   |
| `Cmd+Shift+R` | Переспросить — повтор распознавания (10 сек)    |
| `Cmd+Shift+G` | Показать / скрыть оверлей                      |
| `Cmd+Shift+S` | Открыть настройки                              |
| `Cmd+Shift+M` | Микрофон вкл/выкл                              |
| `Cmd+Shift+Q` | Выйти из приложения                            |

Скриншоты задачи делаются кнопками в самом оверлее (см. ниже), не хоткеями.

## Режим «решение задачи по скриншотам»

Отдельный блок в интерфейсе оверлея для разбора задач по коду:

1. Наведите окно оверлея на участок экрана с задачей.
2. Нажмите **«📷 Снимок»** — снимется область экрана **под окном** (сам
   оверлей в кадр не попадает — у него `setContentProtection`). В панели
   появится превью.
3. Повторите для других фрагментов — условие и данные могут быть на разных
   страницах. Всего до **5 снимков** (лишние можно убрать крестиком).
4. Нажмите **«🧩 Решить»** — все снимки уйдут одним запросом в GPT, в ленте
   появится разбор: подход, полный код решения и оценка сложности.
5. Нужно по-другому? Нажмите **«🎤 Уточнить»** и проговорите просьбу
   («сделай через рекурсию», «оптимизируй по памяти», «перепиши на Python»).
   GPT переделает решение этой же задачи — новым блоком снизу, не стирая
   предыдущее. Уточнять можно несколько раз подряд.

## Как работает обработка разговора

```
Микрофон    ──→ VAD ──→ Whisper (целая реплика) ──→ буфер «Я»
Сист. звук  ──→ VAD ──→ Whisper (целая реплика) ──→ буфер «Собеседник»
                                                        │
                                                  Триггеры (с учётом
                                                   кто говорил)
                                                        │
                                          вопрос? смена темы? тишина >5с?
                                                        │
                                              антиспам (мин. 10 сек)
                                                        │
                                              GPT (текст диалога)
                                                        │
                                              подсказка в оверлее
```

**VAD** (`@ricky0123/vad-web`) ловит начало и конец речи: реплика отправляется
в Whisper целиком, только после паузы ~1.5 сек. Контекстный `prompt` улучшает
распознавание технических терминов.

**Триггеры** (`src/triggers/trigger-manager.js`):

- **Вопрос** — задан собеседником вслух ИЛИ озвучен вами (например, вы читаете
  вслух вопрос из текстового чата) → ждём 2 сек тишины → запрос.
- **Смена темы** (ключевые слова 30-сек отрезков разошлись) → 4 сек → запрос.
- **Я отвечаю своими словами** (не вопрос) → отложенный триггер отменяется.
- **Тишина после вопроса >5 сек** → срочный запрос (я завис).

Голосовые подсказки идут **только текстом** (без скриншотов). Работа с
экраном вынесена в отдельный режим «решение задачи» (см. выше).

## Структура

```
main.js              — main process: ghost://-протокол, loopback-аудио,
                       скриншот области под окном, трей, хоткеи, прокси к OpenAI
preload.js           — мост renderer ↔ main
src/overlay/         — оверлей: HTML/CSS + сборка всей логики
src/settings/        — окно настроек
src/triggers/        — триггеры: вопрос, смена темы, координатор + антиспам
src/audio/           — VadListener: VAD-прослушивание одного источника
src/screen/          — захват области экрана под окном оверлея
src/ai/              — клиент OpenAI (подсказки + решение задач)
src/utils/           — диалоговый буфер, хранилище настроек
src/vendor/vad/      — vendored VAD-движок (vad-web + onnxruntime-web)
```

## Отличия от исходной спецификации

**Распознавание — через OpenAI Whisper, а не Web Speech API.** В Electron
`webkitSpeechRecognition` не работает (Chromium собран без ключа Google Speech
API). VAD режет речь на реплики, каждая реплика уходит в `gpt-4o-mini-transcribe`.

**Звук собеседника — loopback через `getDisplayMedia`.** Обычный
`desktopCapturer` на macOS системный звук не отдаёт. Используется
`setDisplayMediaRequestHandler` с `audio: 'loopback'` (ScreenCaptureKit,
macOS 13+) — стороннее ПО не нужно.

**Кастомный протокол `ghost://`.** VAD-движку нужно грузить ONNX-модель, wasm
и audio-worklet через `fetch()`. На `file://` Chromium это блокирует, поэтому
окна загружаются с защищённого протокола `ghost://app/…` (см. `main.js`).

## Безопасность

- API-ключ хранится в `electron-store` с обфускацией (`encryptionKey`).
- Запросы уходят только на `api.openai.com`.
- Буфер диалога и аудио живут только в памяти, на диск не пишутся.

## Модели

- **Голосовые подсказки** — `gpt-4o-mini`: важна скорость (триггер через 2 сек).
- **Решение задач по коду** — `o4-mini` (reasoning-модель): думает пошагово,
  сильна в алгоритмах. Медленнее, но для режима «по кнопке» это приемлемо.
- **Распознавание речи** — `gpt-4o-mini-transcribe`.

Модели заданы в `src/ai/openai-client.js` (`VOICE_MODEL` / `TASK_MODEL`).

## Стоимость

Ориентировочно **$0.5–1 за час** собеседования. Голосовые подсказки идут без
скриншотов и на дешёвой модели; reasoning-модель тратится только когда вы
явно решаете задачу по скриншотам.

## Ограничения

- `setContentProtection` надёжно работает на Windows 10+ и macOS. На Linux —
  не поддерживается.
- Защищает только от **программного** захвата экрана, не от камеры на монитор.
- Loopback-аудио требует macOS 13+ и разрешения «Запись экрана».
- Снимок области под окном берётся с того дисплея, где находится оверлей.
